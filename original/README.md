# Reproducibility package

This package accompanies **Compute-Constrained Adaptive Electricity Load Forecasting via Offline Policy Learning** (version 7.1, 2 September 2026).

It contains the Python implementation used for the formal experiment matrix, frozen machine-readable outputs, integrity checks, uncertainty analysis, and scripts that regenerate the manuscript tables and figures. Raw datasets are not redistributed because the UCI-ECL and OPSD source files are large and OPSD reuse follows the terms of its primary sources.

## Audited environment

- Windows 11
- Python 3.12
- NumPy 2.5.1
- pandas 3.0.1
- scikit-learn 1.7.2
- SciPy 1.18.0
- ReportLab 4.4.9
- pypdf 6.10.0

The eight main vector figures are regenerated by `code/plot_expanded_rl_figures.py`. The plotting code uses ReportLab when available and falls back to the included `code/simple_canvas.py` for these figures, so figure regeneration does not depend on installing a separate plotting library.

Create an isolated environment from the package root:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Fast verification (no datasets required)

The frozen results can be checked without rerunning model fitting:

```powershell
.\verify_package.ps1 -Python .\.venv\Scripts\python.exe
```

The audit must report four main datasets, one boundary dataset, zero budget violations, 960 formal main-policy evaluations, and 96 boundary-policy evaluations.

## Obtain and preprocess the datasets

The following command downloads the official archives/files, extracts the UCI datasets, records SHA-256 hashes, and creates the three hourly processed files:

```powershell
.\download_and_prepare_data.ps1 -Python .\.venv\Scripts\python.exe
```

The download is approximately 400 MB and extraction requires more than 1 GB of free disk space. Details, citations, and expected paths are in `data/DATA_SOURCES.md`.

## Rerun the study

A small end-to-end smoke run is:

```powershell
.\run_reproduction.ps1 -Python .\.venv\Scripts\python.exe -Smoke
```

The complete formal matrix is:

```powershell
.\run_reproduction.ps1 -Python .\.venv\Scripts\python.exe -Full
```

The full run evaluates Steel, Tetouan, UCI-ECL, and OPSD at 6, 12, 24, and 48 h, under daily budgets 60, 108, and 180, using five chronological folds. Appliances is evaluated as a two-fold short-sample boundary set. It also runs state/depth/seed sensitivity, the gamma-backup grid, gate ablation, and the switching-cost sequential environment. The full run is compute-intensive and is resumable because the main and gate matrices append completed configuration-fold blocks.

## Method safeguards implemented in code

- chronological train/calibration/test splitting;
- horizon-dependent embargoes at outcome boundaries;
- whole-day evaluation and explicit reservation of minimum future cost;
- no test-set choice among algorithms or hyperparameters;
- disjoint fitting, tuning, and deployment-gate calibration blocks;
- fixed action costs and hard daily-budget assertions;
- dataset-fold cluster bootstrap with 20,000 repetitions and seed 20260902;
- fail-closed integrity checks for configuration coverage, action shares, oracle ordering, finite values, and budget compliance.
